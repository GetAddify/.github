# .github

The members-only organization profile of GetAddify.

GitHub gives this repository one role: it shows [profile/README.md](profile/README.md) on the organization page to members of the organization only. Edit that file to change the members-only profile. This `README.md` at the root is not part of the profile.

## What goes here

Only changes to the members-only profile in [profile/README.md](profile/README.md).

Organization tasks, such as renaming or cleaning up labels across repositories, moving or reorganizing issues across repositories, and the automation for such tasks, go to [.github-admin](https://github.com/GetAddify/.github-admin). Work on a single repository stays in that repository.

## The dot repositories

| Repository                                                       | Visibility | Role                                                                    |
| ---------------------------------------------------------------- | ---------- | ----------------------------------------------------------------------- |
| [.github](https://github.com/GetAddify/.github)                  | Public     | The public organization profile and the default community health files |
| [.github-private](https://github.com/GetAddify/.github-private)  | Members    | The members-only organization profile (this repository)                 |
| [.github-admin](https://github.com/GetAddify/.github-admin)      | Admins     | Organization tasks and automation                                       |
